# Анализ тональности отзывов

--- 

Проект представляет собой веб-сервис для автоматического определения тональности  отзывов. Сервис поддерживает четыре различных метода анализа и позволяет обрабатывать как единичные отзывы, так и пакетную загрузку файлов

---
### Модели для определения тональности 


Для нахождения тональности отзыва, пользователь может использовать 1 из 4  моделей:

 1.**Словарный метод** – анализ на основе заранее подготовленных словарей позитивных и негативных слов с учётом усилений (например, «очень») и отрицаний («не»).

2.**KNN (k-ближайших соседей)** – классификация на основе TF‑IDF векторов и подбора оптимального количества соседей через GridSearchCV.

3.RuBERT – локальная трансформерная модель `blanchefort/rubert-base-cased-sentiment`, загружаемая через библиотеку `transformers` и выполняющая inference на CPU/GPU без внешних запросов.

4.**Логистическая регрессия** – обученная модель с TF‑IDF векторизацией, сохраняемая в файл.

---
# Как работает проект


Пользователь посылает свой отзыв или несколько отзывов и выбирает модель,по-которой будет находиться тональность:
1. **Словарный метод**  
    Текст приводится к нижнему регистру, разбивается на слова. Для каждого слова проверяется наличие в словарях, учитываются отрицания и усилители.
    Итоговый сентимент вычисляется как средневзвешенная оценка.

2. **KNN**  
    На основе встроенных списков позитивных, негативных и нейтральных слов/фраз строится TF‑IDF матрица. Выполняется GridSearch по параметрам `n_neighbors`, `metric`, `weights`. Обученный классификатор применяется к вектору входного текста.
    
3. **RuBERT**  
    Модель загружается один раз при старте приложения. Токенизатор и модель работают локально – текст преобразуется в тензоры, выполняется прямой проход. Никаких API-ключей и интернет-соединения не требуется (кроме первой загрузки весов).
    
4. **Логистическая регрессия**  
    Модель предварительно обучается скриптом `train_sentiment_model.py`. Обучение включает:
    
    - TF‑IDF векторизацию (1- и 2-граммы);
    - логистическую регрессию с балансировкой классов.  
   Обученная модель  сохраняется в `trained_logreg_sentiment.joblib`.

  **Веб-приложение**  
    На Flask реализованы:
    
    - `/` – главная страница с интерфейсом (HTML/CSS/JS).
        
    - `/analyze` – анализ одного отзыва (POST JSON с   полями `text` и `method`).
        
    - `/upload` – загрузка и анализ файла (CSV, TXT, JSON).
        
    - `/reviews` – получение последних 15 проанализированных отзывов (GET).  
        Результаты сохраняются в `reviews.json` для отображения в ленте.

Все проанализированные отзывы с метаданными (тональность, оценка, ключевые слова, временная метка) хранятся в `reviews.json`. На главной странице отображается лента последних 15 отзывов.

1.Windows :
  
  1.Установить зависимости  ```pip install -r requirements.txt```
  
  2.Обучить модель логистической регрессии :
		```python train_sentiment_model.py --csv train_reviews.csv```

# Ограничения 

- **Словарный метод** не учитывает порядок слов и тонкие семантические оттенки, ошибается на сарказме.
    
- **KNN** обучается на небольшом синтетическом наборе (списки слов и фраз) – реальные отзывы могут содержать неизвестные лексемы.
    
- **RuBERT** требует стабильного интернет-соединения и может возвращать нестабильные результаты при превышении лимитов бесплатного API.
    
- **Логистическая регрессия** обучается на предоставленном пользователем датасете – если датасет мал или несбалансирован, качество будет низким.
    
- Все методы работают только с русскоязычными текстами (исключение – латиница в словарях минимальна).
    
- Сервис не сохраняет историю после перезапуска (файл `reviews.json` остаётся, но при удалении теряется).
